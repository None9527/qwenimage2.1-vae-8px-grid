# Qwen-Image 2.1：残留交织纹的算子级因果定位（2026-10-12）

## 结论与边界

本轮定位了用户额头图像中可重复测到的 **8像素横纵周期和4像素斜向周期** 的形成/传播环节：解码器中间两组块的第一个 residual block 内，第一次 SiLU 将输入特征的周期性分布差异转为明显周期分量，随后卷积放大或传播它，最终输出保留一部分。官方 VAE 和 Texture-Fix 均复现。

具体位置（零起始编号）：

- `decoder.up_blocks[2].resnets[0].nonlinearity` 第一次调用：输入空间256×256（1024输出的1/4）；2个特征像素对应输出8像素。
- `decoder.up_blocks[3].resnets[0].nonlinearity` 第一次调用：输入空间512×512（输出的1/2）；2个特征像素对应输出4像素。
- 更早的 `up_blocks[1]` 还存在对应输出16像素的类似放大；本轮有特征跟踪和块后干预，尚未对它做同等完整的块内前后控制。

**这不是 SiLU 实现错误的证据，也不是“删除 SiLU/旁路即可修好”。** 点态非线性与当前学到的特征、卷积共同形成周期纹理。内部周期表示本身可能承担正常重建功能。已定位的是上述周期分量的机制，尚不能声称它们覆盖了用户主观指出的所有交织纹；视觉对应已给用户对照图，等待确认。

## 本轮范围与可复现性

- 固定已保存BF16 dense生成latent，无新DiT采样、无FP4、无Sol-Attn、无训练。
- 1024主实验使用stock Diffusers VAE decode，FP32，TF32关闭。2048补充实验使用此前验证过的FP32前缀+分块后缀，只在完整前缀张量内做8像素干预，不在分块内做非局部滤波。
- 154条条件记录，另有3次内部特征基线解码，共157次完成的解码。所有操作为临时forward hook；模型权重没有更新。
- 多组实验撤销hook后重新解码，与原基线ROI逐像素完全相等。
- 原始轨迹、日志和完整图片没有放进这个仓库。下面的表是当次测量留下的数。

## 1. 先测中实际残留信号

对额头ROI `[352,160,672,400]` 做64×64 Hann窗、步长16的局部功率谱平均。以log PSD减去频率平面sigma=2的平滑背景，再取指数作为局部谱峰倍率。

原用户图片、官方解码和Texture-Fix的最显著局部峰均包含 `(fy,fx)=(±1/8,0),(0,±1/8)`，另外存在 `(−1/4,+1/4)` 及其共轭峰。这种局部功率统计不会像全局相位均值一样被不同区域的相位相消。

该倍率只是谱形状指标：低于1代表该频带被挖出凹陷，不能解释为“图像质量更好”，也不能把倍率下降百分比当作伪影消除百分比。

## 2. 旁路与上采样排查

每组块分别把skip/main输出乘0、0.5、1.5，官方和Texture-Fix共50条件。

首级skip减弱能降低8像素峰，但会改变颜色和纹理；第三组main置零则把峰大幅压低，却在图像上留下明显更糟的细网纹。这再次证明梯度能量接近基线也不能保证细节正确。

此前对前三组skip做2×2平均是无效消融：它们输出已经是重复采样。此次直接缩放才是真正改变旁路。

另做38条件，将前三组nearest重复采样分别替换为bilinear/bicubic，作用于skip、main或两者：单改skip没有消除8像素峰，改main经常明显加重周期峰。例如Texture-Fix首级main bilinear的8像素倍率由2.95升到18.69。因此不能把问题简化成“nearest上采样换掉即可”。

## 3. 8像素分量的块内因果控制

固定Texture-Fix与同一个生成latent，在对应频带做周期边界Gaussian notch（输出频率宽度0.0075 cycles/pixel），比较干预前后位置。不是整体低通；滤波发生在特征张量而非RGB图。

| 干预位置 | 输出8像素谱峰倍率 |
|---|---:|
| 不干预 | 2.953 |
| 第三组块输入 | 2.772 |
| 第一个resblock的shortcut输出 | 2.882 |
| 第一个resblock的norm1输出、SiLU之前 | 2.909 |
| 第一次SiLU之后 | 0.494 |
| 随后的conv1之后 | 0.494 |
| 同组最后一个resblock之后 | 0.578 |
| 该组外层skip输出 | 2.877 |
| 撤销干预 | 2.953，像素完全恢复 |

滤波放在SiLU之前无法有效阻止周期分量再次形成；放在之后明显抑制。卷积前后结果几乎相同也符合该窄带线性滤波与卷积在内部区域近似可交换。

这比“去掉整条残差后图像变化了”更有定位意义。最后一个resblock后干预的破坏较小：额头RGB变化RMS约4.90灰度级，sigma4低频变化RMS约0.089灰度级。

## 4. SiLU如何产生这些分量

精确恒等式：

`SiLU(x) = x/2 + (x/2)*tanh(x/2)`。

前项为奇对称线性部分，后项为偶对称非线性部分；小输入时后项近似`x²/4`。因此相位间的特征分布/二阶统计差异，即使在均值中不明显，也可以在激活之后成为周期分量。

Texture-Fix额头特征实测：

| 位置 | 目标相位RMS / 空间特征标准差 |
|---|---:|
| 第三组norm1后，8像素横纵分量 | 3.49% |
| 第一次SiLU后 | 25.35% |
| conv1后 | 64.30% |
| 第四组norm1后，4像素斜向分量 | 0.73% |
| 第一次SiLU后 | 16.26% |

SiLU偶对称部分的目标相位向量范数/完整输出相位向量范数分别为0.972和0.986；它与二次项对应相位向量的cosine分别0.974和0.998。这里是向量范数比与相关性，**不是独立方差贡献率**。

官方VAE得到相近结果：第三组3.58%→24.94%→63.59%，第四组0.77%→16.51%。这不是Texture-Fix独有现象。

这解释了为什么高频细节区域值得重点检查；不能直接推导“所有相邻像素对比强的图像都会出问题”。也尚未区分所有高阶谐波与采样混叠的贡献，不能笼统宣称已证明aliasing是唯一机制。

## 5. 联合干预、恢复与独立内容控制

在第三组最后一个resblock后处理8像素轴向分量，在第四组最后一个resblock后处理4像素斜向分量。使用Texture-Fix：

| 指标 | 基线 | 联合干预 |
|---|---:|---:|
| 8像素局部谱峰倍率 | 2.953 | 0.578 |
| 4像素斜向谱峰倍率 | 2.045 | 0.865 |
| 额头梯度RMS/基线 | 1.000 | 1.005 |
| 额头低频变化RMS，0–255 | 0 | 0.091 |

对照的四列是官方、Texture-Fix、联合干预、恢复。第三列横向周期结构有所变化，依然有复杂交织细节。梯度RMS没有下降不等于细节完全正确；不存在真实生成图GT，不能宣称无损。

2048小熊猫只做8像素前缀干预：倍率1.573→0.584，低频变化0.108灰度级，梯度比1.004。1024人像：8像素1.463→0.690。说明频率按输出像素而不是归一化画面宽度固定；与分辨率增大后同等显示大小纹理更密的观察一致。但1024/2048 latent是不同生成内容，不是完全配对尺度实验。

两张真实照片512原生裁剪，使用Texture-Fix E/D，再加入联合干预：

- hair PSNR 36.791→36.726 dB；重建图变化RMS 0.529灰度级。
- fur PSNR 34.491→34.367 dB；重建图变化RMS 0.871灰度级。

存在轻微真实重建损失，样本只有两张。滤波会挖掉真实频带，不能直接作为通用部署方案。

## 6. 更早层、多尺度与Texture-Fix边界

逐组第一个SiLU的完整2×2相位RMS/空间标准差：

| 对应输出周期 | 激活前 | 激活后 |
|---|---:|---:|
| 32像素，stage0 | 7.85% | 7.53% |
| 16像素，stage1 | 6.26% | 36.33% |
| 8像素，stage2 | 3.49% | 25.44% |
| 4像素，stage3 | 1.17% | 30.45% |
| 2像素，stage4 | 23.76% | 23.83% |

这里包括横纵和对角全部相位，故不能直接与上一节的单一方向分量比较。stage1/2/3一起硬滤波后谱峰更低，但额头RGB改变RMS升至20.71灰度级，毛发组织也改变。**不应把多尺度全部滤掉当作成功修复。**

Texture-Fix 的说明指出初版纹理训练主要解冻最高分辨率两组块和输出头；后续版本另做了全解码器尺度/偏置调整和FP16数值处理。当前权重几乎全部与官方不同，包含大幅等效缩放，因此不能用原始权重L2差异判断哪些层训练了纹理，也不能说当前低分辨率权重逐位没变。文件级差异只供审计，不作纹理因果证据。

## 修复工作的约束

现在有理由把后续纹理修复检查范围扩展到stage1/2/3，并在激活前后监测相位条件分布与对应输出周期；不能只盯最后一级shortcut或只训练输出尾部。

训练目标仍需保护低频颜色/结构与真实纹理，配合多尺度真实图像监督判断周期结构是否不自然。不能要求所有内部周期分量归零，也不能将SiLU简单替换成线性函数。GAN/LPIPS的训练成因尚未由本轮实验验证，不把作者对原始训练的推测当作事实。

本轮没有启动训练或改动生产内核。一个实验统计函数发生浮点裁剪索引错误，修正为整数 stride 后重跑完成；不影响已完成的其他条件。
